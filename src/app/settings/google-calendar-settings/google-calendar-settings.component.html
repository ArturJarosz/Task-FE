How to get a service account key

  1. Open Google Cloud Console and pick a project, or create one.
  2. Go to APIs & Services › Library, find Google Calendar API and click Enable.
  3. Go to IAM & Admin › Service accounts and click Create service account. Give it a name; it needs no roles.
  4. Open the new account, go to the Keys tab and choose Add key › Create new key › JSON. A .json file downloads.
  5. Paste the file's contents here or use Load from file, then save.

Keep the file private: anyone who has it can use the account.
